## Using the AutoHotkey hotstrings in this repository

If you want to use the bundled AutoHotkey hotstrings (`personal_hotstrings.ahk`) with your own GitHub workflow, follow these steps:

1. Clone or download this repository to a Windows machine that has [AutoHotkey v1](https://www.autohotkey.com/) installed.
2. Open `personal_hotstrings.ahk` in a text editor and skim the sections to familiarize yourself with the grouped hotstrings (contact info, documentation prompts, application shortcuts, etc.).
3. Double-click the script to run it with AutoHotkey. Keep the repo synced (e.g., `git pull`) whenever updates are made so you always have the latest hotstrings.
4. Customize any hotstring values to match your own details, then commit and push your changes if you want them versioned in GitHub.
5. Optionally export only the `personal_hotstrings.ahk` file to other machines and keep it under version control here so you can track revisions over time.
